# Screenshots — shot list (PrestaShop)

The guides reference the PNG files below: `quick-start.md` (Polish) uses this folder, `quick-start.en.md` (English) uses `en/` — the same file names, captured with the back office in English.

## Regenerating

The screenshots are generated by Playwright from the QA project in the parent repository (`qa/docs-screenshots/`):

```bash
cd qa
npm run docs:screenshots                      # Polish -> module/docs/screenshots/
DOCS_LANG=en npm run docs:screenshots         # English -> module/docs/screenshots/en/
npm run docs:screenshots -- -g "configuration" # only the matching tests
```

- The language comes from the **admin employee's language** — for the English set switch the employee (and the English language, if inactive) to English for the run and switch it back afterwards.
- The runner masks data that must not appear in a guide: buyer name / e-mail / phone / address / company / tax id (sample values), InPost organization names ("Moja firma") and ids, the Client ID.
- The dictionary-values example (06b) seeds a temporary category, attribute and feature and removes them afterwards; all other shots use the existing data (product and order ids in `DATA` in `screens.spec.ts`).
- Viewport 1440×900 at 2× scale; each shot is cropped to its panel or dialog.
